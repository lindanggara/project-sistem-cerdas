# Dashboard Menfess Radar

Dashboard direncanakan menggunakan Streamlit untuk menampilkan:

1. Ringkasan jumlah menfess dan rentang waktu data.
2. Distribusi topik dan contoh representatif yang aman ditampilkan.
3. Tren volume topik dari waktu ke waktu.
4. Form prediksi peluang dibalas jika model dan fitur input telah tersedia.
5. Metrik evaluasi model dan batasan penggunaannya.

Jalankan dari root repositori dengan `streamlit run dashboard/app.py` setelah `app.py`, data, dan model tersedia.
